Context: fixes two related problems in the university card's bottom-row eye/heart icons, confirmed by reading the live source.

1. The icons aren't rendering visibly (showing as blank space next to the view/like counts). Root cause: the CSS targets plain `button`/`svg` tag selectors, which have weak specificity against MUI's own injected classes — unreliable. Elsewhere in this exact file (`scss/pc/general.scss`, `.agent-general-card .buttons`), the same kind of icon is styled successfully using MUI's own class selectors (`.MuiSvgIcon-colorPrimary { color: #e8856a; }`), which is the proven, working pattern.
2. The like/favorite logic here doesn't match how every other card in the codebase implements it. The established, working pattern — used in `libs/components/university/UniversityCard.tsx` and `libs/components/common/AgentCard.tsx` — is: show `<FavoriteBorderIcon />` (outline heart) when not liked, and `<FavoriteIcon color={'primary'} />` (filled heart, using MUI's `color` prop) when liked. This card instead uses an unstyled `<FavoriteIcon />` for "not liked" (no border/outline variant) and an inline `style={{color:'#e8856a'}}` for "liked" — inconsistent with the rest of the site and part of why the icon isn't reliably visible.

The fix: adopt the exact same `FavoriteBorderIcon` / `FavoriteIcon color="primary"` pattern already used elsewhere, and restyle via MUI's own class selectors (matching the already-proven `.MuiSvgIcon-colorPrimary` approach in this same file) instead of plain tag selectors. The like/favorite click handler itself (`likeUniversityHandler`) is untouched — only which icon component renders, and how it's styled.
