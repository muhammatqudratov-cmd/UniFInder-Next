## Fix 1 — `public/locales/ru/common.json`

Find:
```json
	"University type": "Тип недвижимости",
	"Rooms": "Комната",
	"Advanced": "Расширенные",
	"University Search": "поиск Имущество",
```

Replace with:
```json
	"University type": "Тип университета",
	"Rooms": "Комнаты",
	"Advanced": "Расширенные",
	"University Search": "Поиск университета",
```

What changed and why:
- `"University type"`: "Тип недвижимости" ("Property type") → "Тип университета" ("University type") — matches the English key's actual meaning.
- `"Rooms"`: "Комната" (singular "Room") → "Комнаты" (plural "Rooms") — matches the English key's plural form; this is the dormitory-rooms search filter label.
- `"Advanced"`: unchanged — already correct.
- `"University Search"`: "поиск Имущество" (grammatically broken "search Property") → "Поиск университета" ("University Search") — matches the English key's meaning and fixes the broken grammar.

Do not change any other key in this file (`Home`, `Universities`, `Agents`, `Community`, `My Page`, `CS`, `Login`, `Register`, `Location`, etc.) — those are already correct.

## Fix 2 — `public/locales/kr/common.json`

Find:
```json
	"Universities": "매물",
```

Replace with:
```json
	"Universities": "대학교",
```

Find:
```json
	"University type": "매물 유형",
```

Replace with:
```json
	"University type": "대학교 유형",
```

Find:
```json
	"University Search": "매물 찾기",
```

Replace with:
```json
	"University Search": "대학교 찾기",
```

What changed and why: "매물" means "property listing / property for sale" (a real-estate term) — it doesn't belong in a university-search app. "대학교" is the correct Korean word for "university". `University type` and `University Search` used the same wrong "매물" root word and are corrected the same way.

Do not change any other key in this file (`Home`, `Agents`, `Community`, `My Page`, `CS`, `Login`, `Register`, `Location`, `Rooms`, `Advanced`, etc.) — those are already correct (e.g. `"CS": "고객센터"` is the correct term for a Notice+FAQ support section, and was not touched).
