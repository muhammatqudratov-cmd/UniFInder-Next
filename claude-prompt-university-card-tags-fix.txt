Context: fixes a real bug found in the university card, confirmed by reading the live source against the reference design screenshot. The bottom row is supposed to show a "Dormitory" tag only when `university.universityDormitory` is true, and a "Scholarship" tag only when `university.universityScholarship` is true — exactly like the reference, where a card with only scholarship shows just the "SCHOLARSHIP" pill (no Dormitory anything), and a card with only dormitory shows just "DORMITORY" (no Scholarship anything). Right now the code always renders both labels — when a flag is false it falls back to rendering the same word as plain gray text instead of hiding it, so every card incorrectly shows both "Dormitory" and "Scholarship" in some form. Separately, the pill's colors are currently a coral/peach combo, but the reference design uses the site's neutral warm-gray/beige + dark-text tokens already used elsewhere in this redesign.

This is a presentational-only fix: conditional rendering of existing boolean fields already fetched on `university` (no GraphQL/query change), plus a CSS color correction.

## `libs/components/common/UniversityBigCard.tsx`

Find:

```tsx
					<div className={'bott'}>
						<div>
							{university?.universityDormitory ? <p>Dormitory</p> : <span>Dormitory</span>}
							{university?.universityScholarship ? <p>Scholarship</p> : <span>Scholarship</span>}
						</div>
```

Replace with:

```tsx
					<div className={'bott'}>
						<div>
							{university?.universityDormitory && <p>Dormitory</p>}
							{university?.universityScholarship && <p>Scholarship</p>}
						</div>
```
