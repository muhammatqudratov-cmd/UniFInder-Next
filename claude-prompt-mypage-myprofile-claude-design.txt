No mutation logic, no form-submit logic, no routing/category logic changes anywhere.

Files touched: `libs/components/mypage/MyMenu.tsx`, `libs/components/mypage/MyProfile.tsx` (className-only, no JSX restructuring beyond what's specified), `scss/pc/mypage/mypage.scss`, `scss/pc/mypage/myProfile.scss`.

## Why two small count badges are added to the sidebar (grounded in real data, not invented)

The reference screenshot shows "My Universities" and "My Favorites" sidebar items with small count badges (4 and 7). Both counts already exist elsewhere in the codebase as the `metaCounter[0].total` of an already-used query:
- "My Universities" count → `GET_AGENT_UNIVERSITIES` (already used by `MyUniversities.tsx`, only meaningful for `memberType === 'AGENT'`, which is also exactly when this nav item itself is rendered)
- "My Favorites" count → `GET_FAVORITES` (already used by `MyFavorites.tsx`)

Following the same precedent as the Community sidebar tab counts (4 extra lightweight calls to an existing operation with `limit: 1`), `MyMenu.tsx` will call both of these existing queries itself with `limit: 1`, purely to read `metaCounter[0].total` for the badge — no new GraphQL operation is introduced.

## 1. `libs/components/mypage/MyMenu.tsx` — add the two count queries

Add to the imports:

```tsx
import { useQuery } from '@apollo/client';
import { GET_AGENT_UNIVERSITIES, GET_FAVORITES } from '../../../apollo/user/query';
```

(`useReactiveVar` is already imported from `@apollo/client` — just add `useQuery` to that same import line instead of duplicating it.)

Inside the component, right after `const user = useReactiveVar(userVar);`, add:

```tsx
/** APOLLO REQUESTS **/
const { data: myUniversitiesCountData } = useQuery(GET_AGENT_UNIVERSITIES, {
	fetchPolicy: 'network-only',
	skip: user?.memberType !== 'AGENT',
	variables: {
		input: {
			page: 1,
			limit: 1,
			sort: 'createdAt',
			search: { universityStatus: 'ACTIVE' },
		},
	},
});
const myUniversitiesCount = myUniversitiesCountData?.getAgentUniversities?.metaCounter[0]?.total ?? 0;

const { data: myFavoritesCountData } = useQuery(GET_FAVORITES, {
	fetchPolicy: 'network-only',
	variables: { input: { page: 1, limit: 1 } },
});
const myFavoritesCount = myFavoritesCountData?.getFavorites?.metaCounter[0]?.total ?? 0;
```
