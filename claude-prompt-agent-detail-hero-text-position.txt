Context: pure CSS change, no logic. Two positioning mismatches in the `/agent/detail` hero text block (breadcrumb / "VERIFIED AGENT" badge / heading / lead), confirmed by reading `scss/pc/main.scss`:

1. `.agent-detail-hero-container` is still a fixed `width: 825px` block centered with `margin-left/right: auto`. But the page's own `.container` below it (in `scss/pc/agent/detail.scss`, holding the white profile card) was already fixed in an earlier change to `max-width: 1300px; padding: 0 24px;` to match the rest of the site. Because the hero text block above still uses the old 825px centered width while the content below now uses 1300px, their left edges no longer line up — the breadcrumb/heading appear shifted right relative to the profile card underneath.
2. `margin-top: 51px` was tuned for the old, shorter `330px` hero. Now that `.agent-detail-hero`'s height was corrected to `557px` (matching every other page's hero), this text sits too close to the top. Other hero text blocks at this same `557px` height use `margin-top: 120px` (see `.agent-hero-container` and `.container.has-stats`, both `margin-top: 120px`).
