Context: pure CSS change, no logic. On the Community page sidebar (`pages/community/index.tsx`, styled by `scss/pc/community/community.scss`), two buttons currently don't use the new warm-gray accent color:
1. The active "Free Board" tab (`.tab-button.active` — also covers Recommendation/News/Humor when selected) currently has `background-color: transparent`, so the sidebar shows no fill behind the selected tab, only bold dark text.
2. The "+ Write a post" button (`.write-post-btn`, routes to `/mypage?category=writeArticle`) currently has `background: #1c1b18` (near-black).

You want both filled with `#f5f3ef` instead. Since `#f5f3ef` is a light tone, both buttons keep dark text for readability: the active tab keeps its existing dark `#1c1b18` label text and coral `#e8856a`/`#d2674c` dot+count (these already read fine on a light fill, so they are left unchanged), and the "+ Write a post" button switches its text from white to dark `#1c1b18` since white-on-`#f5f3ef` would not be readable. No routing, tab-switching logic, or query/mutation code is touched — only `background`/`color` values in `community.scss`.
