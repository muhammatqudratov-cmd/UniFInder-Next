## 2. Rotating word state
Add, near the existing `heroVisible` state in `withLayoutBasic`:
```tsx
const [rotatingWordIndex, setRotatingWordIndex] = useState(0);
const [rotatingWordKey, setRotatingWordKey] = useState(0);

useEffect(() => {
	if (!memoizedValues.marqueeItems) return;
	const id = setInterval(() => {
		setRotatingWordIndex((prev) => (prev + 1) % memoizedValues.marqueeItems!.length);
		setRotatingWordKey((prev) => prev + 1);
	}, 1400);
	return () => clearInterval(id);
}, [memoizedValues.marqueeItems]);
```
This cycles through `marqueeItems` (Stanford, NUS, MIT, Cambridge, etc.) every 1.4 seconds. `rotatingWordKey` forces React to remount the `<span>` on every tick so the CSS entrance animation (section 3/4 below) replays each time — used for the "behind {word}" line in the heading.
