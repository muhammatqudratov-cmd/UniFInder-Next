--- STEP 1: Add a debounced useEffect that fires searchFilter update on every keystroke ---

Find (the existing useEffect blocks, place the new one right after this block):
	useEffect(() => {}, [searchFilter]);

Replace with:
	useEffect(() => {}, [searchFilter]);

	useEffect(() => {
		const timeout = setTimeout(() => {
			setSearchFilter((prev: UniversitiesInquiry) => ({
				...prev,
				page: 1,
				search: { ...prev.search, text: searchText },
			}));
		}, 400);
		return () => clearTimeout(timeout);
	}, [searchText]);
