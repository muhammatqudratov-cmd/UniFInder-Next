FILE 2 — .env.example  (NEW FILE — create at project root, next to package.json)
=====================================================================

Create this file with exactly this content:

```
# Copy this file's variable NAMES into your hosting platform's Environment Variables
# settings (e.g. Vercel Project Settings → Environment Variables) and fill in REAL
# production values before deploying. Do not commit actual secrets to this file —
# it only documents which variables the app requires; it contains no real values.

# Backend REST API base URL (used by libs/config.ts, apollo/client.ts, several components)
REACT_APP_API_URL=

# Backend GraphQL endpoint (used by apollo/client.ts, Teditor.tsx, MyProfile.tsx)
REACT_APP_API_GRAPHQL_URL=

# Backend WebSocket endpoint for GraphQL subscriptions (used by apollo/client.ts)
REACT_APP_API_WS=

# Same GraphQL endpoint, exposed under a NEXT_PUBLIC_ name for pages/api/telegram.ts
# and AddNewUniversity.tsx — keep this equal to REACT_APP_API_GRAPHQL_URL above.
NEXT_PUBLIC_API_GRAPHQL_URL=

# Telegram bot token (server-side only, used in pages/api/telegram.ts) — keep secret
TELEGRAM_BOT_TOKEN=

# Telegram bot public ID (used by components/TelegramLoginButton.tsx)
NEXT_PUBLIC_TELEGRAM_BOT_ID=

# Telegram bot username, no @ (used by components/TelegramLoginButton.tsx)
NEXT_PUBLIC_TELEGRAM_BOT_NAME=
```

Why this file is needed: `.env.development` and `.env.local` (which currently hold the only copies of these 7 variables) are both excluded by `.gitignore`, so they are never uploaded to a git-based host. `.env.development` is also never read by Next.js in production builds at all (only `next dev` reads it). This `.env.example` is NOT gitignored, so it travels with the repo and serves as a permanent checklist of exactly which variables must be set in the hosting platform's dashboard with real production values — it does not replace that manual dashboard step, which only the project owner can perform (real backend URLs and the bot token must be entered there, not in this file).
