Context: pure CSS change, no logic. Five homepage section wrappers in `scss/pc/homepage/homepage.scss` currently have inconsistent backgrounds (`white`, `#f4f3ef`, `#ffffff`) for their outer section, while the inner cards inside each section are already `white` (`.trend-uni-card`, `.popular-uni-card`, `.top-uni-card`, `.agent-card`, `.community-card`). This change unifies all five section backgrounds to one warm gray tone — `#f5f3ef` — so the white cards show clear, consistent contrast across every section. Only the `background` property on each section wrapper changes; nothing else in any of these rules is touched, and no JSX/component file changes at all.

## 1. Trend Universities — line ~1242

Find:

```scss
.trend-universities {
	padding: 72px 48px;
	background: white;
	width: 100%;
	box-sizing: border-box;
}
```

Replace with:

```scss
.trend-universities {
	padding: 72px 48px;
	background: #f5f3ef;
	width: 100%;
	box-sizing: border-box;
}
```
