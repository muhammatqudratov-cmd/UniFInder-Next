Goal:
1. The title (`<strong>{t(memoizedValues.title)}</strong>`) and the paragraph (`<p className={'lead'}>...</p>`) should animate in with a fade + slide-up effect on mount (start ~16px below final position and opacity 0, ending at translateY(0) and opacity 1), title animating first, paragraph following with a small delay (~150ms stagger).

Keep the `+`, `k`, and `★` suffixes — only the numeric portion animates (e.g. animate 0 → 240 for "240+", 0 → 18 for "18k", 0 → 9.4 with one decimal for "9.4★").

Implementation:
1. In `LayoutBasic.tsx`, change the `stats` data shape from `{ value: string; label: string }[]` to also carry numeric animation info, OR keep `value` as the display string and derive the animated number with a small parser — simplest approach: add a `numericValue: number` and `suffix: string` field to each stat object for `/university`:
   ```
   stats = [
     { numericValue: 240, suffix: '+', decimals: 0, label: 'Universities' },
     { numericValue: 18, suffix: 'k', decimals: 0, label: 'Programs' },
     { numericValue: 9.4, suffix: '★', decimals: 1, label: 'Avg. rating' },
   ]
   ```
   Update the TypeScript type for `stats` accordingly (it's a local field inside the `useMemo` return, not used elsewhere, so this is safe).

2. Create a small reusable `CountUpStat` component (can be defined locally at the bottom of `LayoutBasic.tsx` or in a new file `libs/components/layout/CountUpStat.tsx`):
   ```tsx
   const CountUpStat = ({ target, suffix, decimals = 0, duration = 900 }: { target: number; suffix: string; decimals?: number; duration?: number }) => {
     const [value, setValue] = useState(0);
     useEffect(() => {
       let start: number | null = null;
       const step = (timestamp: number) => {
         if (start === null) start = timestamp;
         const progress = Math.min((timestamp - start) / duration, 1);
         setValue(target * progress);
         if (progress < 1) requestAnimationFrame(step);
       };
       const raf = requestAnimationFrame(step);
       return () => cancelAnimationFrame(raf);
     }, [target, duration]);
     return <strong>{value.toFixed(decimals)}{suffix}</strong>;
   };
   ```
   Import `useState`/`useEffect` (already imported at the top of the file) and use this component inside the `.stats-row` map instead of the static `<strong>{s.value}</strong>`:
   ```tsx
   <Stack className={'stat'}>
     <CountUpStat target={s.numericValue} suffix={s.suffix} decimals={s.decimals} />
     <span>{s.label}</span>
   </Stack>
   ```
