Context: TopAgents.tsx throws a runtime error:
  "TypeError: Cannot read properties of undefined (reading 'autoplay')"
  at webpack-internal:/node_modules/swiper/modules/autoplay/autoplay.js (47:1)

Root cause: The mobile Swiper in TopAgents.tsx imports Autoplay and passes it in
`modules={[Autoplay]}`, but there is no `autoplay={{ ... }}` prop on the Swiper element.
Swiper's Autoplay module reads `swiper.params.autoplay` on init — when the prop is absent
it is `undefined`, causing the crash.

Fix: remove Autoplay from the import AND from the modules array in the mobile Swiper.
The mobile swiper does not need autoplay — it is a simple drag-to-scroll list.

Edit 2 — remove Autoplay from the Swiper modules prop.

Find:

Replace with:
