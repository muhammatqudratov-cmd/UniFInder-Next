Context: precisely-scoped UI removal, not a redesign. On the sign-up form, remove the "Agent" registration-type option — agent status is assigned by the admin directly in the database, not chosen by the user at sign-up.

## Confirmed in `pages/account/join.tsx`

```tsx
<Box className={'register'}>
	{!loginView && (
		<div className={'type-option'}>
			<span className={'text'}>I want to be registered as:</span>
			<div>
				<FormGroup>
					<FormControlLabel
						control={
							<Checkbox
								size="small"
								name={'USER'}
								onChange={checkUserTypeHandler}
								checked={input?.type == 'USER'}
							/>
						}
						label="User"
					/>
				</FormGroup>
				<FormGroup>
					<FormControlLabel
						control={
							<Checkbox
								size="small"
								name={'AGENT'}
								onChange={checkUserTypeHandler}
								checked={input?.type == 'AGENT'}
							/>
						}
						label="Agent"
					/>
				</FormGroup>
			</div>
		</div>
	)}
```

`input.type` already defaults to `'USER'` (`const [input, setInput] = useState({ nick: '', password: '', phone: '', type: 'USER' });`), and `checkUserTypeHandler` resets `type` back to `'USER'` whenever a checkbox is unchecked. Removing the "Agent" checkbox simply means a new sign-up can never set `type` to `'AGENT'` from this form — it always stays `'USER'`, which is correct since agent accounts should only be created/promoted by an admin directly in the database, not self-selected at sign-up.
