Goal: Add show/hide password toggle to the Login/Signup form.
Currently the password input has type="text" — password is always visible. Fix this by:
1. Changing type to "password" by default
2. Adding an eye icon button to toggle visibility

Do NOT change any login/signup logic, handlers, validation, or other inputs.

CHANGE 1: pages/account/join.tsx — Add import
=====================================================================

Find:
import { Box, Button, Checkbox, FormControlLabel, FormGroup, Stack } from '@mui/material';

Replace with:
import { Box, Button, Checkbox, FormControlLabel, FormGroup, Stack, IconButton } from '@mui/material';
import Visibility from '@mui/icons-material/Visibility';
import VisibilityOff from '@mui/icons-material/VisibilityOff';

CHANGE 2: pages/account/join.tsx — Add showPassword state
=====================================================================

Find:
	const [loginView, setLoginView] = useState<boolean>(true);

	const [showPassword, setShowPassword] = useState<boolean>(false);

CHANGE 3: pages/account/join.tsx — Replace password input block
=====================================================================

Find:
						<div className={'input-box'}>
							<span>Password</span>
							<input
								type="text"
								placeholder={'Enter password'}
								onChange={(e) => handleInput('password', e.target.value)}
								required={true}
								onKeyDown={(event) => {
									if (event.key == 'Enter' && loginView) doLogin();
									if (event.key == 'Enter' && !loginView) doSignUp();
								}}
							/>
						</div>

Replace with:
						<div className={'input-box'}>
							<span>Password</span>
							<div className={'password-wrapper'}>
								<input
									type={showPassword ? 'text' : 'password'}
									placeholder={'Enter password'}
									onChange={(e) => handleInput('password', e.target.value)}
									required={true}
									onKeyDown={(event) => {
										if (event.key == 'Enter' && loginView) doLogin();
										if (event.key == 'Enter' && !loginView) doSignUp();
									}}
								/>
								<IconButton
									className={'eye-btn'}
									onClick={() => setShowPassword((prev) => !prev)}
									tabIndex={-1}
								>
									{showPassword ? (
										<VisibilityOff fontSize="small" />
									) : (
										<Visibility fontSize="small" />
									)}
								</IconButton>
							</div>
						</div>
