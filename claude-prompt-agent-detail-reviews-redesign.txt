Context: redesign the "Reviews" section on `/agent/detail` to match a reference design exactly — a two-column layout: left column is the reviews list ("What students say"), right column is a dark "Leave a review" card with a star-rating input above the review textarea. Currently this section is a single stacked column (reviews list on top, plain light "Leave A Review" box below it), and individual reviews share one gray panel with divider lines instead of being separate white cards.

Important grounding notes:
- There is no rating field anywhere in the data model (`CommentInput` in `libs/types/comment/comment.input.ts` only has `commentGroup`, `commentContent`, `commentRefId`, `memberId` — no rating). So the "Your rating" stars in the reference design are implemented as **decorative, local UI state only** — they are NOT sent to the backend and do NOT change `insertCommentData` or the `createCommentHandler`/GraphQL mutation in any way. This was confirmed with the project owner.
- Per-review star ratings (the reference's 5-star / 4-star rows per individual review) are NOT added to `ReviewCard.tsx`, because `Comment` (`libs/types/comment/comment.ts`) has no rating field either — there is no real data to show, and we never invent values. The `.review-card .info .right { svg { color: #edf023; } }` rule in the SCSS is leftover/dead CSS for a feature that was never wired up; it gets removed as cleanup.
- The relative-time format ("2 days ago", "1 week ago") in the reference is a presentational format change to the existing `comment.createdAt` field — switching `react-moment`'s `format` prop to `fromNow`. No data binding changes.
- All GraphQL queries, the `createCommentHandler` mutation call, `likeUniversityHandler`, pagination handlers, and all existing state variables are otherwise fully preserved — only JSX structure, copy text, and SCSS change.
