Context: makes the "All / Dormitory / Scholarship" pills on `/agent/detail` actually filter the "Listed universities" card grid. This was previously left as a non-functional, purely visual element (by explicit earlier choice), but the requirement has changed — they must now actually filter.

Important constraint: the GraphQL query used here (`GET_UNIVERSITIES` with `AgentUniversitiesInquiry`, defined in `libs/types/university/university.input.ts`) only supports `search: { universityStatus }` server-side — there is no `universityDormitory`/`universityScholarship` filter param on this query's input type, and adding one would mean changing the GraphQL schema/backend, which is out of scope. So this is implemented as a **client-side filter** over the already-fetched `agentUniversities` list (which already includes `universityDormitory`/`universityScholarship` booleans on every item — confirmed in `libs/types/university/university.ts` and already used by `UniversityBigCard` to render the Dormitory/Scholarship tags). No GraphQL query, mutation, or variables change — only one new local React state value and a `.filter()` over data that is already in memory.


Replace with:

```tsx
						<Stack className={'card-wrap'}>
							{agentUniversities
								.filter((university: University) => {
									if (portfolioFilter === 'dormitory') return !!university?.universityDormitory;
									if (portfolioFilter === 'scholarship') return !!university?.universityScholarship;
									return true;
								})
								.map((university: University) => {
									return (
										<div className={'wrap-main'} key={university?._id}>
											<UniversityBigCard
												university={university}
												likeUniversityHandler={likeUniversityHandler}
												key={university?._id}
											/>
										</div>
									);
								})}
						</Stack>
```
