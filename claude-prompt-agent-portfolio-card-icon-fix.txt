Context: found the real root cause of why the university card's bottom-row icons stayed invisible on `/agent/detail` despite multiple fixes already applied to `scss/pc/general.scss`. There is a SECOND, page-specific override block in `scss/pc/agent/detail.scss` (a compact 261x277px variant of the same card, used only in the agent's portfolio grid) that still has the old broken rule: `button { width: 12px; height: 12px; padding: 0; ... }` — forcing the MUI `<IconButton>`'s own box down to a tiny fixed size, which hides/squishes the icon (the same root cause already fixed elsewhere, just not here). It also still references the old class name `.buttons-box`, which no longer matches since the wrapper div's class was already renamed to `buttons` in `libs/components/common/UniversityBigCard.tsx`. Because this block is more deeply nested (higher specificity) than the fix already applied in `general.scss`, it was silently overriding it — which is why the card on `/agent/detail` never visually changed.

```scss
							.bott {
```
