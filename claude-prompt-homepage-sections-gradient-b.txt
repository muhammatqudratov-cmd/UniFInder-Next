Context: pure CSS change, no logic. Five homepage section wrappers in `scss/pc/homepage/homepage.scss` currently all share the warm gray `#f5f3ef` background: Trend Universities, Popular Universities, Top Universities, Top Agents, and Community Board (which contains the "Free Board" tab — it has no separate background of its own, it inherits the section's background). This replaces all five with the same dark gradient — `linear-gradient(135deg, #15140f 0%, #1c2620 50%, #1a2230 100%)` (black → forest green → navy) — already approved and applied to the homepage hero. Only the `background` property on each section wrapper changes; the white cards inside each section (`.trend-uni-card`, `.popular-uni-card`, `.top-uni-card`, `.agent-card`, `.community-card`) keep their existing white background untouched, so they show clear contrast against the new dark sections — same pattern as the hero. No JSX/component file changes, no GraphQL/state/handler changes.
