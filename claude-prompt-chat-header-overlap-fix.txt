Context: the chat header redesign caused a real bug. `.chat-top` contains two elements from `Chat.tsx` — the "Online Chat" title `<div>` and a `RippleBadge` (online-user-count indicator) with an inline negative margin `style={{ margin: '-18px 0 0 21px' }}`. That negative margin was only safe under the *original* `.chat-top` layout (`flex-direction: row`, single line, large 30px/54px line-height row), where the badge sat beside the title. The redesign changed `.chat-top` to `flex-direction: column`, which stacks the title, the `::after` subtitle, and the badge vertically — and the badge's `-18px` top margin now pulls it directly up onto the title text instead of sitting beside it, causing the visible overlapping/double text in the screenshot. Fix: keep `.chat-top` itself as a `row` flex container (so the `RippleBadge` sits beside the text exactly as it always has, unaffected by this redesign), and move the column-stacked title+subtitle styling onto only the title's own wrapper div, isolated from the badge. Also reducing the title font size per request.

Pure CSS, no JSX changes, no `Chat.tsx` logic changes (the `RippleBadge` markup, socket/online-user-count logic stay 100% untouched — only the CSS layout direction and font sizes change).
