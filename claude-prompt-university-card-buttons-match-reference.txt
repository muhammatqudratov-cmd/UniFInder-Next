Context: the eye/heart icons in the bottom row of `UniversityBigCard.tsx` are still invisible after two prior CSS attempts (both confirmed applied in `scss/pc/general.scss`, both targeting the outer MUI `<IconButton>` box — first with a fixed `width/height: 16px`, then with `padding: 0` + a nested `svg` size rule + `.MuiIconButton-root`/`.MuiSvgIcon-root` class selectors). Since both attempts at constraining the `<IconButton>`'s own box failed to fix visibility, stop fighting the IconButton entirely.

Instead, replace this row's styling with the exact approach already proven to work on the reference card: `libs/components/university/UniversityCard.tsx`'s bottom-row icons (styled by `.buttons { svg { width: 24px; height: 24px; cursor: pointer; } }` in `scss/pc/university/university.scss`, lines ~471-484). That CSS never touches the `<IconButton>`'s own padding/margin/width/height at all — it only sets the size directly on the inner `svg`, and lets MUI's `IconButton` keep its native box. This is the simplest, already-working pattern on this site, so we replace this card's button-row logic with that same approach instead of patching further.

The class name on the wrapper div is also renamed from `buttons-box` to `buttons` to match the reference card 1:1.
