Context: pure CSS change, no logic. The `/agent/detail` page content is rendering noticeably narrower than every other page on the site (Universities, Agents, Community, etc.), because this page's own `.container` rule overrides the site-wide container width with a much smaller `max-width: 825px` instead of the site standard `1300px` (confirmed in `scss/app.scss`: `#pc-wrap .container { width: 1300px; margin: 0 auto; }`, which every other page relies on). This makes the hero/profile card/portfolio section look cramped with a large empty gap on the right, as seen in the screenshot.

## `scss/pc/agent/detail.scss`

Find:

```scss
		.container {
			display: flex;
			flex-direction: column;
			align-items: center;
			width: 100%;
			max-width: 825px;
			margin: 0 auto;
			padding: 0;
			box-sizing: border-box;
```

Replace with:

```scss
		.container {
			display: flex;
			flex-direction: column;
			align-items: center;
			width: 100%;
			max-width: 1300px;
			margin: 0 auto;
			padding: 0 24px;
			box-sizing: border-box;
```

Do not change anything else in this file — only this one `max-width`/`padding` pair on the page's `.container` selector.

---

Verify after implementing:
1. Open `/agent/detail` and compare its content width to `/university` or `/agents` — the profile card, portfolio header, and card grid now span the same width as those other pages (1300px container, same as the rest of the site), with no large empty gap on the right.
2. The hero banner above the profile card is unaffected (it's already full-width/separate from this `.container`).
3. The card grid still wraps responsively inside the new wider container — no overflow or broken layout.
4. No GraphQL/Apollo/React logic touched — this is a single CSS value change.
