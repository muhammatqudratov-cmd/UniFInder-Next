Context: redesign the university card visual style in TrendUniversities, TopUniversities, and PopularUniversities sections to match a modern full-bleed photo-card design:
- Full-bleed university photo covering the entire card
- Rounded corners (24px)
- Dark gradient overlay rising from the bottom (~70% height)
- Heart/like button: top-right, semi-transparent frosted circle
- University name: large bold white text, bottom-left, over the gradient
- Subtitle: university address, lighter white text below the name
- Info row: tuition price (with label icon) + campus size (with expand icon), white text
- White pill "View Details" button pinned at card bottom (16px from edges)

ALL data bindings, click handlers, like logic, Apollo queries, router.push calls, and component interfaces remain unchanged — only JSX markup and inline styles are changed. No SCSS file is touched. No prop types change.

Desktop cards are rendered inline inside the parent components. Mobile cards use separate Card files.
New MUI icons needed: `LocalOfferIcon` (for tuition), `AspectRatioIcon` (for campus size) — both are in @mui/icons-material which is already installed.
