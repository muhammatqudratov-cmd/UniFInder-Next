Context: pure CSS change, no logic. Four list/landing pages currently use flat light backgrounds for their root page container: Universities (`#university-list-page`, `#fafaf8`), Agents (`.agent-list-page`, `#fafaf8`), Community (`#community-list-page`, `#fafaf8`), and My Page (`#my-page`, `#f3efe7`). This replaces all four with the same dark gradient — `linear-gradient(135deg, #15140f 0%, #1c2620 50%, #1a2230 100%)` (black → forest green → navy) — already approved for the homepage hero section. Only the root `background` declaration on each page wrapper changes; every inner element (filter bars, cards, inputs, sidebars) already has its own explicit `background: #fff` / `#ffffff`, so they keep showing as white cards on top of the new dark page background, the same contrast pattern as the homepage hero already uses. No JSX/component file changes, no GraphQL/state/handler changes.
