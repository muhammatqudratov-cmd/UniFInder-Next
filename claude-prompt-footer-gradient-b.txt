Context: pure CSS (+ one inline-style) change, no logic. The site footer's visible background lives in `.newsletter-section` in `scss/pc/homepage/homepage.scss` (confirmed via `libs/components/Footer.tsx` line 72 — `#footer` itself is `background: transparent !important` per an existing code comment, so `.newsletter-section` is the real, global footer background used on every page). Switching it from the current light beige (`#F4F3EF`) to gradient B (`linear-gradient(135deg, #15140f 0%, #1c2620 50%, #1a2230 100%)`) — the same black → forest green → navy gradient already used on the hero sections.

Because the background is going from light to dark, every footer text/icon color that was designed for a light background needs to flip to a light/translucent-white equivalent so it stays legible. The white "Subscribe" input/button and any element with its own light pill/card background are left untouched.
