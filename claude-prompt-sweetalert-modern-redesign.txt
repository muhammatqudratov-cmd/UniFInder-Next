This is a pure CSS rewrite of the same `.swal2-*` class overrides already in `scss/app.scss` — no JSX, no `libs/sweetAlert.ts`, no call-site logic changes anywhere.

Because SweetAlert2 draws its default icon as a large circle with absolutely-positioned checkmark/x line divs tuned for that bigger size, those default line/ring elements are hidden via `display:none` and replaced with a simple `::after` character glyph (✕ / ✓ / ?) so the icon can be shrunk down to a small square badge cleanly, with no JS or extra image assets needed.
