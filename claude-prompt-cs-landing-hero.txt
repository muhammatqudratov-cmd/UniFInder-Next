Context: new presentational hero section for the `/cs` (Customer Support) page. This does not exist anywhere in the codebase yet — it replaces only the top header block of the current `/cs` page (the plain "Cs center / I will answer your questions" block in `pages/cs/index.tsx`). The Notice/FAQ tabs and their content below stay completely untouched — no GraphQL query, Apollo state, or existing handler logic is touched anywhere in this change. `@react-three/fiber`, `@react-three/drei`, and `three` are already installed dependencies (see `package.json`), so no new packages are needed.

Design spec (grounded in the approved reference screenshot):
- Full-width hero, background = gradient B: `linear-gradient(135deg, #15140f 0%, #1c2620 50%, #1a2230 100%)`.
- Left column: small caps eyebrow "SUPPORT · HELP CENTER" in violet (`#7c6df0`), big bold heading "CS" in white, subtitle text "We're here to help, anytime." in `rgba(255, 255, 255, 0.65)`, and a small caption row below with a violet dot + "Move your cursor over the shape to interact" in `rgba(255, 255, 255, 0.5)`.
- Right column: an interactive 3D shape (torus knot) rendered with `@react-three/fiber`, colored coral `#e8856a` (matching the project's existing coral accent token), that slowly auto-rotates and also tilts to follow the cursor position when the mouse moves over the hero.

## 1. New file: `libs/components/cs/CsHero.tsx`

```tsx
import React, { useRef } from 'react';
import { Canvas, useFrame, useThree } from '@react-three/fiber';
import { Stack } from '@mui/material';

function InteractiveKnot() {
	const meshRef = useRef<any>(null);
	const { pointer } = useThree();

	useFrame((_, delta) => {
		if (!meshRef.current) return;
		meshRef.current.rotation.x += delta * 0.25;
		meshRef.current.rotation.y += delta * 0.35;
		// Tilt gently toward the cursor position, on top of the constant auto-rotation.
		meshRef.current.rotation.x += (pointer.y * 0.4 - meshRef.current.rotation.x * 0.02) * delta;
		meshRef.current.rotation.y += (pointer.x * 0.4 - meshRef.current.rotation.y * 0.02) * delta;
	});

	return (
		<mesh ref={meshRef}>
			<torusKnotGeometry args={[1.1, 0.38, 200, 32]} />
			<meshStandardMaterial color={'#e8856a'} roughness={0.25} metalness={0.4} />
		</mesh>
	);
}

export default function CsHero() {
	return (
		<Stack className={'cs-hero'}>
			<Stack className={'cs-hero-left'}>
				<span className={'cs-hero-eyebrow'}>SUPPORT · HELP CENTER</span>
				<h1 className={'cs-hero-title'}>CS</h1>
				<p className={'cs-hero-sub'}>We're here to help, anytime.</p>
				<div className={'cs-hero-caption'}>
					<span className={'cs-hero-dot'} />
					Move your cursor over the shape to interact
				</div>
			</Stack>
			<Stack className={'cs-hero-right'}>
				<Canvas camera={{ position: [0, 0, 4.2] }}>
					<ambientLight intensity={0.6} />
					<directionalLight position={[3, 3, 3]} intensity={1.1} />
					<InteractiveKnot />
				</Canvas>
			</Stack>
		</Stack>
	);
}
```
