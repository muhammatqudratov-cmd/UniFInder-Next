Context: pure CSS change, no logic. In the reference design, every university card photo has a dark tinted overlay (the same black → forest-green → navy gradient family used across the site's hero sections), so the price tag, "top" status badge, and favorite heart icon sit on a darkened photo and read clearly. Right now the real photo renders at full brightness with no tint, so the card looks visually inconsistent with the reference (this is the "design bir xil bo'lishi kerak" gap — the photo treatment itself, not the badge positions, which are already correct).

This is implemented as a semi-transparent gradient layered on top of the photo via a `::before` pseudo-element — it does not touch the actual `background-image` (the real photo URL/data binding stays exactly as-is), it only sits visually on top of it.

## `scss/pc/general.scss`

Find:

```scss
	.card-img {
		position: relative;
		width: 100%;
		height: 264px;
		background-size: cover;
		cursor: pointer;
		div.status {
			position: absolute;
			padding: 6px 12px;
			left: 12px;
			top: 12px;
```

Replace with:

```scss
	.card-img {
		position: relative;
		width: 100%;
		height: 264px;
		background-size: cover;
		cursor: pointer;
		&::before {
			content: '';
			position: absolute;
			inset: 0;
			z-index: 1;
			pointer-events: none;
			background: linear-gradient(
				135deg,
				rgba(21, 20, 15, 0.55) 0%,
				rgba(28, 38, 32, 0.45) 50%,
				rgba(26, 34, 48, 0.5) 100%
			);
		}
		div.status {
			position: absolute;
			z-index: 2;
			padding: 6px 12px;
			left: 12px;
			top: 12px;
```

This adds the dark gradient tint (`&::before`) and bumps `div.status` to `z-index: 2` so it stays visible above the new overlay. Two more selectors in the same `.card-img` block need the same `z-index: 2` bump so they also stay above the tint — find each one individually:

Find:

```scss
		div.price {
			position: absolute;
			padding: 8px 14px;
			left: 12px;
```

Replace with:

```scss
		div.price {
			position: absolute;
			z-index: 2;
			padding: 8px 14px;
			left: 12px;
```

Find:

```scss
		.fav-btn {
```
