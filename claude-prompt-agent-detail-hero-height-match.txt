Context: pure CSS change, no logic. The `/agent/detail` page's dark hero/banner section is shorter (vertically smaller) than every other page's hero. Confirmed in `scss/pc/main.scss`: the base rule is `.header-basic { height: 557px; }`, and other page-specific variants like `.agent-hero` (used on `/agent`) explicitly match this at `height: 557px`. But `.agent-detail-hero` (used only on `/agent/detail`) currently overrides it down to `height: 330px`, making this page's hero noticeably shorter than the rest of the site.

## `scss/pc/main.scss`

Find:

```scss
		&.agent-detail-hero {
			height: 330px;
			background: linear-gradient(135deg, #15140f 0%, #1c2620 50%, #1a2230 100%);
```

Replace with:

```scss
		&.agent-detail-hero {
			height: 557px;
			background: linear-gradient(135deg, #15140f 0%, #1c2620 50%, #1a2230 100%);
```

Do not change anything else in this block — the gradient background, `::before`/`::after` dot-grid and glow overlays, and everything inside `.agent-detail-hero-container` stay exactly as they are; only the `height` value changes.
